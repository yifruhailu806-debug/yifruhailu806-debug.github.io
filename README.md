# Yifru Hailu Abebe — Professional Portfolio

A responsive static portfolio website made with HTML, CSS and JavaScript. It is suitable for free hosting on GitHub Pages.

## Before publishing

1. Replace `ADD_YOUR_EMAIL` and `ADD_YOUR_PHONE` in `index.html` with the contact details you want employers to see.
2. Add your own portrait photo at `assets/profile.jpg` (JPG format recommended). Keep the filename exactly `profile.jpg`.
3. Review your education and employment dates/descriptions for accuracy.
4. Do not publish private information you do not want publicly visible.

## Preview on your computer

- Extract the ZIP file.
- Open the `yifru_portfolio` folder in VS Code.
- Open `index.html` in a browser, or use the VS Code Live Server extension.

## Publish free with GitHub Pages

1. Sign in at https://github.com/ (create a free account if needed).
2. Create a **Public** repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
3. Upload the contents of this folder (upload `index.html`, the `assets` folder, and this README; do not upload the ZIP as the only file).
4. Open repository **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Choose branch **main** and folder **/(root)**, then click **Save**.
7. Wait a few minutes. Your site address will be `https://YOUR-GITHUB-USERNAME.github.io`.

## Photo

The page includes a photo placeholder. Save your chosen portrait as `assets/profile.jpg`. A clear, professional head-and-shoulders photo works best.

## Important

Your published GitHub Pages website is public. Only add contact details and photographs you are comfortable sharing with employers and the public.
